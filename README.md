# Percepta concept

An unofficial design concept by Gaurav Basantani: check one shift before Nightingale's schedule posts.

A made-up nurse manager reviews the January night schedule that Nightingale drafted for her unit. One nurse wrote "no Mondays or Wednesdays, I have a class" in a note instead of changing her availability, so every staffing rule passes with her on a Wednesday. Nightingale asks about that one shift, and the manager swaps it with one tap before the schedule posts.
